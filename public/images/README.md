# Website Images

Place your website screenshot images in this folder.

## Recommended Image Specifications:
- **Format**: JPG or PNG
- **Dimensions**: 1200x800px (or similar aspect ratio)
- **File Size**: Optimize images to keep file size small (< 500KB per image)

## File Naming:
The following images are needed (place them in this `/public/images/` folder):

1. `datafitt.jpg` - DataFitt website screenshot
2. `alfalah-maid.jpg` - Alfalah Maid Services website screenshot
3. `aitemaad-maid.jpg` - Aitemaad Maid Services website screenshot
4. `alfalah-puredrop.jpg` - Alfalah Pure Drop website screenshot
5. `alfalah-patientcare.jpg` - Alfalah Patient Care Services website screenshot
6. `alfalah-handyman.jpg` - Alfalah Handyman Services website screenshot

You can update the image paths in `components/WebsiteCarousel.tsx` if you want to use different file names.

## Image Sources:
You can take screenshots of your websites using:
- Browser screenshot tools
- Online screenshot services
- Design tools (Figma, etc.)
- Screen capture software

Make sure the images showcase your websites well!
